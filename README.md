# Streamlit Test App 🚀

Aplicación web interactiva desarrollada con **Streamlit** para la visualización y análisis exploratorio de datos.

---

## 🛠️ Tecnologías Utilizadas

* **Python 3.10+**
* **Streamlit** — Framework de interfaz gráfica
* **Pandas** — Manipulación y limpieza de datos
* **Plotly Express** — Gráficos interactivos
